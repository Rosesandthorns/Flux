# **App Name**: Flux

## Core Features:

- Server Rail: Thin vertical bar displaying server icons, with 'Home' icon and '+' button for adding servers.
- Channel Sidebar: Lists text and voice channels. 'User Profile' widget at the bottom with avatar, username, and settings.
- Main Chat Area Header: Top header displaying the current channel name (#channel-name).
- Message Display: Scrollable area showing user avatar, name, timestamp, and text content.
- Message Input Bar: Input bar at the bottom with 'upload' and 'emoji' icons for composing and sending messages.
- Collapsible Sidebars: Make sidebars collapsible into a hamburger menu for mobile responsiveness.

## Style Guidelines:

- Primary color: Electric Violet (#8000FF) for a vibrant and modern feel.
- Background color: Deep charcoal and slate-grey (#313338) as the primary background.
- Accent color: Use a slightly lighter shade of slate-grey (#424549) for hovered states.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a modern, machined, objective, neutral look, suitable for both headlines and body text.
- Simple, outlined icons for server and channel navigation, with custom icons for upload and emoji.
- Use Flexbox to ensure the chat area expands to fill available space. Sidebars should have a glassmorphism effect.
- Subtle hover effects and transition animations for interactive elements (buttons, channel list items).
